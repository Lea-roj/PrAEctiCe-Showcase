# PrAEctiCe Showcase
This repository presents selected materials, presentations, and technical documentation from my participation in the European PrAEctiCe research project focused on digitalization, IoT systems, and data-driven applications for agriculture and fisheries.

The project involved international collaboration with Maseno University (Kenya) and development of practical digital solutions for real-world field environments.

## My Contribution

During the project, I contributed to:
- Data collection and analysis from IoT and sensor devices
- Development and testing of digital agriculture applications
- Technical documentation and user guide preparation
- Workshops and training sessions for project participants
- International collaboration and presentation of project results
